# Wolven Language

Official Visual Studio Code language support for Wolven.

## Features

- `.wlv` file support
- Wolven syntax highlighting
- Automatic bracket closing
- Wolven Run command
- Runs the current file using the Wolven interpreter

## Run a Wolven File

Open a `.wlv` file.

Press:

Ctrl + Shift + P

Then search:

Wolven: Run Current File

The extension runs:

node index.js your-file.wlv

## Requirements

- Node.js
- Wolven project
